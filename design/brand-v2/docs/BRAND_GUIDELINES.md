# EVIDORIX — Brand Standards v2

**Positioning:** Open-source clinical evidence research and operations research.

**Tagline:** From evidence to defensible decisions.

## Visual approach
Swiss Editorial × Scientific Modernism. Gridded and information-dense where needed, otherwise generous negative space. Never generic AI/brain/neural network iconography.

## Logo
The primary logo is outlined vector `wordmark-ink.svg`. The X includes one precise vermilion cut. For dark fields use `wordmark-reversed.svg`. `mark-ink.svg` is the only compact mark. Clear space at least 1/4 of mark height, and never distort aspect ratio. Avoid placing the logo on busy photographs.

## Palette
| Role | HEX | Application |
|---|---|---|
| Ink | `#17191A` | Headlines, structure, dark fields |
| Cut | `#C83C2D` | One purposeful selection signal |
| Paper | `#F6F3EC` | Editorial surfaces |
| White | `#FFFEFB` | Interfaces and high-contrast surfaces |
| Slate | `#6B7278` | Secondary labels only |

Use red as typographic emphasis or brand signal, **never** as a clinical safety status or treatment endorsement. No gradients or glows.

## Typography
Inter Display in display headlines, Inter in UI and dense tables, Noto Serif for considered editorial flourishes, monospace for code and numeric models. Use installed/system licensed fonts, do not distribute fonts in the project.

## Voice
Direct, evidence-oriented, precise. State study source/versions when claiming clinical findings. Do not claim the software optimizes all treatments or issues medically validated prescriptions.

## Applications
GitHub social preview 1280×640. LinkedIn cover 1584×396. SVG versions are editable, PNG versions are deployment-ready.

## Legal
EVIDORIX brand name and mark have not been cleared for trademark registration or exclusive use. Perform a formal search before commercial registration.

## Product language
Use English (en-US) for brand manuals, public communications, application interfaces, technical documentation and product-generated prose. Original source-language citations may be retained for verification.
